# Testing

Run `npm run build` after TypeScript, dependency, or application changes. It performs TypeScript checking and production bundling; it does not execute browser shaders or verify usability.

For visual or interaction changes, complete the relevant browser checks in `docs/execution/test_evidence.md`. Record actual results and distinguish pending checks from completed ones. No automated test framework is currently configured. Documentation-only edits require link/content review, not an application rebuild.
