# Conventions

Use TypeScript for application behavior and CSS for layout and presentation. Keep both language variants aligned when changing user-facing content. Preserve semantic HTML, keyboard navigation, visible focus styles, and reduced-motion behavior.

Use the résumé or confirmed owner-provided information for career claims. Preserve evaluation context for metrics. Do not invent public project destinations or results.

Dispose graphics resources and observers when replacing the scene. Avoid adding server infrastructure or external services without a concrete requirement.
